# Advanced features

Beyond the core STL I/O, repair, and signed-distance API documented in
the [API companion guide](/guide/api/), FOSSIL ships **thirteen
algorithmic primitives** drawn from the libigl / CGAL geometry-
processing toolkit. They turn FOSSIL from "an STL parser with an AABB
tree" into a CFD preprocessing toolchain on its own. Every item is a
single TBP on `surface_stl_object`.

The pages here explain **what each algorithm is**, **when to use it**,
**when not to**, and **how to call it from Fortran**. For the raw API
signature, see the [autogenerated reference](/api/) or the
[`surface_stl_object` companion page](/guide/api/surface-stl-object); the
advanced-feature pages cross-link to both.

## The shipped primitives

| Feature | TBP | Reference |
|---|---|---|
| [Boolean operations](/guide/advanced/booleans) | `surface%boolean(other, op, status)` | Zhou et al. *Mesh Arrangements* (SIGGRAPH 2016) |
| [Self-intersection detection / resolution](/guide/advanced/self-intersection) | `surface%find_self_intersections(...)` / `surface%resolve_self_intersections(...)` | Möller tri-tri |
| [Mesh decimation (QEM)](/guide/advanced/decimate) | `surface%decimate(target_facets, status)` | Garland & Heckbert (SIGGRAPH 1997) |
| [Generalized / fast winding number](/guide/advanced/winding-number) | `surface%winding_number(point, beta)` | Jacobson 2013 + Barill 2018 |
| [Marching cubes / isosurface extraction](/guide/advanced/marching-cubes) | `extract_isosurface(values, bmin, bmax, iso, ...)` | Lorensen-Cline (SIGGRAPH 1987) |
| [Alpha wrapping](/guide/advanced/alpha-wrap) | `surface%alpha_wrap(alpha, offset, ...)` | Portaneri et al. (SIGGRAPH 2022) |
| [Isotropic remeshing](/guide/advanced/isotropic-remesh) | `surface%isotropic_remesh(target_length, ...)` | Botsch & Kobbelt (SGP 2004) |
| [SDF segmentation](/guide/advanced/sdf-segmentation) | `surface%segment_sdf(...)` | Shapira, Shamir & Cohen-Or (Vis. Comp. 2008) |
| [Ray-mesh intersection queries](/guide/advanced/ray-queries) | `surface%intersect_ray_first/_all/_any(...)` | Möller-Trumbore |
| [Cotangent Laplacian + barycentric mass](/guide/advanced/cotangent-laplacian) | `surface%cotangent_laplacian(L, M, status)` | Pinkall & Polthier 1993; Meyer et al. 2003 |
| [Per-vertex Gaussian + mean curvature](/guide/advanced/curvature) | `surface%gaussian_curvature(K, status)` / `surface%mean_curvature(H, status)` | Meyer et al. 2003 |
| [Mesh smoothing (explicit + Taubin)](/guide/advanced/smoothing) | `surface%smooth(method, lambda, mu, iterations, status)` | Taubin (SIGGRAPH 1995) |
| [Hole filling](/guide/advanced/hole-filling) | `surface%fill_holes(max_hole_edges, max_hole_size, ...)` | Liepa (SGP 2003) |

## Execution backends and grid fields

Four pages cover something other than a surface TBP, so they are not counted
among the primitives:

| Page | Entry points | What it adds |
|---|---|---|
| [GPU distance queries](/guide/advanced/device-distance) | `surface%enter_device()` / `surface%distance_many_device(...)` / `surface%exit_device()` | Batch signed distance on the GPU via OpenACC (nvfortran), SAH BVH only, bit-exact vs the CPU path |
| [Signed-distance field](/guide/advanced/distance-field) | `distance_field_object`: `initialize(x, y, z, ng)` / `compute(surface, ...)` | Signed distance of every cell of a stretched rectilinear grid: exact narrow band, flood-fill signs, fast sweeping (OpenMP, bit-exact); used by `fossil_ib_generator`; 2-D fields from curves |
| [Immersed-boundary queries](/guide/advanced/ib-queries) | `query_many(_device)`, `probe_many`, `image_points`, `store_closest` | Closest point, normal, feature, body per point (CPU/GPU), probe and image points with visibility, ambiguous foot points, vector level set; 3-D and 2-D |
| [Sign algorithms at sharp features](/guide/advanced/sign-benchmark) | `fossil_test_sign_bench(_2d, _device)` | Misclassification of the four sign algorithms (and the naive closest-facet normal) at edges, vertices, 2-D corners and cusps, 1e-1 to 1e-12 L, clean and dirty meshes; recommended defaults |
| [Cut-cell geometry](/guide/advanced/cut-cells) | `line_crossings(_many, _device)`, `cell_wall_fractions`, `cut_cells`, `cut_cells_3d` | Exact grid-line crossings and wall fractions (CPU/GPU), 2-D cut cells with pieces, 3-D face fractions and cell volumes; exact topology, round-off measures |
| [AMR tagging](/guide/advanced/amr-tagging) | `box_classify_many(_device)`, `box_intersects_surface`, `tag_block` | Blocks and cells cut, near, inside or outside from the BVH alone (CPU/GPU), signed tag bands on stretched blocks; 3-D and 2-D |
| [2-D geometry (curves)](/guide/advanced/2d-geometry) | `curve_object`, `slice_surface(surface, normal_axis, level, curve)` | Closed polylines for quadtree solvers: segment BVH, signed distance, 2-D fast winding number, exact orient2d, STL slicing, repair, batched CPU/device queries |

RANSAC shape detection was deliberately **not** shipped — see the
[roadmap issue](https://github.com/szaghi/FOSSIL/issues/18) for the
detailed rationale, summarised: detected primitives still need manual BC
assignment, real CAD STL fragments badly under primitive-family fitting,
and SDF segmentation does the user-facing facet-grouping job better.

## How the pages are structured

Each advanced-feature page follows the same template:

> **What it does** — one paragraph in plain English, in CFD-relevant
> terms.
>
> **Pipeline** — the algorithm in 3-7 stages, with diagrams where it
> helps.
>
> **API** — the call site, signature explained, defaults justified.
>
> **Example** — a complete, runnable Fortran program. Compiled by CI
> (same pipeline as `docs/guide/api/`).
>
> **Known limitations** — the things you'd hit in production. Always
> includes the documented gaps from the implementation issue (alpha-
> wrap single-pass MVP, isotropic-remesh inward Laplacian bias,
> boolean axis-aligned coplanar overlap, etc.).
>
> **References** — the source paper and any directly relevant
> follow-ups.
